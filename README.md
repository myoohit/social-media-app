# social-media-app


A social platform concept that connects **entrepreneurs, investors, and startups** — helping them **pitch ideas, collaborate, and invest**.

## 🎯 Overview
This project aims to build a space where:
- Entrepreneurs can pitch their ideas 💡  
- Investors can discover and fund startups 💰  
- Professionals can network and collaborate 🤝  

## 🎨 My Contribution
